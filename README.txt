PHANTOM DIRECTIVE — website concept
===================================

Files:
- index.html: page structure/content
- style.css: responsive cyberpunk styling
- script.js: mobile navigation, archive dialogs, placeholder actions

Preview:
Open index.html in a browser. Fonts load from Google Fonts when online; system fallbacks are included.

Before publishing:
1. Finalize brand/name after a full token, domain, and trademark check. This package uses PHANTOM DIRECTIVE as a provisional concept.
2. Add official X/Telegram/community URLs in index.html and script.js.
3. Add the real Solana mint/contract address only after launch; the copy button is deliberately a placeholder.
4. Replace fictional archive items or label them as community fiction (current site labels them as fictional concept).
5. Do not add investment promises or guaranteed-return language.
6. Deploy the folder using a static host such as GitHub Pages, Cloudflare Pages, or Netlify. No server or database required for this prototype.

This is a front-end prototype, not a live hosted website. No wallet connection or transaction code is included.
